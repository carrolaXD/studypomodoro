Apoio

Usa a Study Pomodoro num PC com Windows 10 ou 11 de 64 bits. A instalação é feita pela Microsoft Store.

Preciso de uma conta?

Podes usar o temporizador, os sons e as estatísticas offline. A conta Google é opcional e serve para sincronizar o progresso e as preferências entre PCs.

Como posso reportar um problema ou sugerir uma ideia?

Abrir o formulário de feedback. Se estiveres a reportar um problema, indica a versão da app, a versão do Windows e os passos para o reproduzir.

Como posso apagar os dados sincronizados?

Envia um pedido para pedrocarrola2006@gmail.com. A política de privacidade explica que dados existem e onde ficam guardados.
